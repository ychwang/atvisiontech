# 机器人初始化与连接

完整 Python/C++ 程序集中在模块示例。本页仅说明初始化与连接接口的输入、返回和使用限制。

## 初始化机器人

`/at/robot/init_robot` · Service · `weld_interfaces/srv/ATRobotInit`

初始化机器人驱动和通信配置，不负责上电。

所选驱动及依赖已安装。首次初始化可初始化驱动并启动后台连接尝试；已有机器人实例的重配置还要求连接变更门空闲、自动模式关闭、任务状态为空/完成/错误/停止取消，且已连接机器人静止并退出拖动。跨品牌切换不能在线执行，须将目标类型设为默认后重启。

### 请求参数

字段 | 类型 | 含义与填写方式 | 有效值／限制
--- | --- | --- | ---
`robot_type` | string | 机器人驱动类型，大小写敏感。`Aubo`：遨博 AUBO；`xCore`：珞石 ROKAE xCore；`Fuc`：FANUC；`DUCO`：DUCO。 | 可选值：`Aubo`、`xCore`、`Fuc`、`DUCO`。不接受 `aubo`、`xcore`、`fanuc`、`UR` 等别名。
`robot_subtype` | string | 机器人子型号，按原文保存，不转换大小写。示例值 `i7`；部署时填写目标驱动支持的型号。 | 必填非空字符串；空字符串返回 `400 / The robot subtype is empty.`。接口不提供统一型号枚举。
`robot_ip` | string | 机器人控制器的点分十进制 IPv4 地址。示例环境：`192.168.1.8`。不要填写端口、协议或主机名，也不得与 `local_ip` 相同。 | 四段 0–255 的纯数字 IPv4，不接受前导零；空值返回 400。
`local_ip` | string | 填写运行服务端的机器人通信网卡IPv4地址，如 `192.168.1.16`，不是第三方SDK主机地址；必须不同于robot_ip。入口不检查此地址是否真的绑定本机网卡。 | 同robot_ip格式；ROS省略时为""而非127.0.0.1（内部结构默认被请求覆盖）。
`robot_scope` | float64 | 填写有限正数工作范围，用于运动处理时校验前三个位置分量；不是所有运动的统一安全限位。 | 必须为有限正数；拒绝 `<=0`、NaN 和无穷值。

### 响应字段

字段 | 类型 | 含义与解析方式 | 取值说明
--- | --- | --- | ---
`status` | int16 | 200可能表示首次驱动初始化并启动后台连接尝试、相同配置且已连接/已订阅的幂等返回、同端点仅scope/range更新，或Aubo/DUCO同品牌安全断开重连成功；不能统一解释为已经连接、上电或到位。400包含参数校验及服务端安全切换/初始化失败；500为捕获异常。 | 200 / 400 / 500
`data` | string | 始终为空字符串 `""`；不是 JSON，不要调用 JSON 解析。 | 始终 `""`
`message` | string | 成功时为空字符串。失败时返回参数校验文本、`W-03-008` 跨品牌重启提示、在线切换不支持提示、`Robot is busy` 或通用初始化/重连失败提示。 | 结合 `status` 判断，不按固定文本推断成功。

### 请求结构（仅格式说明）

```json
{
  "robot_type": "Aubo",
  "robot_subtype": "i7",
  "robot_ip": "192.0.2.10",
  "local_ip": "192.0.2.20",
  "robot_scope": 1000.0
}
```

### 响应结构

```json
{
  "status": 200,
  "data": "",
  "message": ""
}
```

先判断 `status`。首次初始化会加载驱动并启动后台连接线程，`200` 不表示连接已建立。已有实例时，相同配置且已连接、已订阅可直接返回成功；仅调整同端点的 scope/range 可原地更新；Aubo/DUCO 在空闲门禁满足时可执行同品牌断开和重连。跨品牌切换保持当前连接并返回 `W-03-008`；xCore/Fuc 不支持在线重配置。任何 `200` 都不表示已上电、运动到位或完成数据库持久化。

### 使用限制

- `DUCO` 仅适用于包含 DUCO 驱动的部署。示例子型号 `i7` 不代表所有 AUBO 型号均受支持。
- 已有实例的重配置有连接变更门禁：自动模式、非终态任务、连接变更并发、机器人非静止或拖动模式都会拒绝；不是旧文档所述无门禁重置。
- 跨品牌切换返回W-03-008并保持当前连接；Aubo/DUCO才有当前显式在线重连路径，xCore/Fuc除精确幂等情况外fail closed。
- 首次驱动初始化可能启动后台连接尝试；同品牌重配可能同步断开/重连，因此该接口不是无连接副作用的纯配置写入。

## 连接/断开机器人

`/at/robot/connect` · Service · `weld_interfaces/srv/ATBool`

连接或断开机器人。

机器人已初始化，且系统初始化完成。

### 请求参数

字段 | 类型 | 含义与填写方式 | 有效值／限制
--- | --- | --- | ---
`enable` | bool | 填写true连接已初始化的机器人控制器；false先请求驱动下电，再断开连接。不是ROS节点或SDK连接；省略时ROS默认false，会执行下电/断开分支。 | 仅ROS布尔true/false；SDK要求bool，不传字符串"false"。

### 响应字段

字段 | 类型 | 含义与解析方式 | 取值说明
--- | --- | --- | ---
`status` | int16 | 连接/断开驱动调用返回0时200；机器人尚未初始化、重复连接、网络/驱动失败或系统初始化中为400；捕获异常为500。 | 200 / 400 / 500
`data` | string | 所有分支未赋值，保持""，无JSON业务数据。 | —
`message` | string | 成功""；未初始化Robot Init Fail；驱动失败 robot connect or disconnect error；系统初始化中 System is initializing, please try again later.；异常 Internal server error。 | —
`result` | int16 | 所有分支未赋业务值，保持ROS默认0；不是驱动连接/断开返回码，不能用result==0判断成功。 | 默认0，无业务判定作用

### 请求结构（仅格式说明）

```json
{
  "enable": true
}
```

### 响应结构

```json
{
  "status": 200,
  "data": "",
  "message": "",
  "result": 0
}
```

使用 `status==200` 判断连接或断开请求已完成，再查询机器人状态中的 `connect_status` 确认当前连接状态。`result` 保持默认值 0，没有业务判定作用。`connect(true)` 返回成功后还会应用当前机器人配置，但该步骤的返回值不并入 `status`。断开流程先下电再断开，`200` 不能单独证明下电成功。重复连接可能返回 400，不是幂等成功。

### 断联与恢复

驱动连接使用3秒wait_for检查，不保证ROS服务总耗时。超时后不要自动重试，先回读设备状态。
