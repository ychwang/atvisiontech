# 机器人位置与运动参数

示例环境：Aubo / i7H，机器人 `192.168.1.8`，系统主机 `192.168.1.101`。下列位置仅用于说明字段、单位和请求格式，不是可直接执行的目标点。

## 当前位置与单位

只读接口：`/at/robot/get_pos`，Service `weld_interfaces/srv/ATRobotGetPos`。

```bash
ros2 service call /at/robot/get_pos weld_interfaces/srv/ATRobotGetPos '{request: {}}'
```

成功响应的 `status=0`、`message=""`，三个数组均包含 6 个有限数。本接口以 `status=0` 表示正常返回，不使用通用的 200；`400` 表示查询失败。

|数组|顺序|单位/坐标|
|---|---|---|
|cur_pos|x,y,z,rx,ry,rz|TCP，基座坐标；xyz为mm，后三项为ZYX欧拉角rad|
|joint_pos|J1,J2,J3,J4,J5,J6|六关节角，rad|
|flan_pos|x,y,z,rx,ry,rz|无TCP偏移的法兰位姿；xyz为mm，ZYX欧拉角rad|

连续状态数据可能存在微小位姿和速度波动。单次位置响应不能证明机器人持续静止或满足运动安全条件。

## 运动参数单位（Aubo）

|运动|位置/目标|速度|加速度|交融半径|
|---|---|---|---|---|
|轴向连续运动|move_type选择轴；direction取+1/-1，无目标位置|XYZ：mm/s；WPR/J轴：rad/s|接口无此字段|接口无此字段|
|关节运动|绝对[J1..J6]，rad|rad/s|rad/s²|mm；0不交融|
|直线运动|绝对基座TCP；xyz mm、ZYX欧拉角rad|平移mm/s|平移m/s²|mm；0不交融|
|圆弧运动|当前位置为起点；途经点/终点同直线位姿单位|平移mm/s|平移m/s²|mm；0不交融|

Aubo 输入范围：关节速度 `0 < v ≤ 2.5 rad/s`，平移速度 `0 < v ≤ 2500 mm/s`，加速度 `0 < a ≤ 4`（关节为 `rad/s²`，平移为 `m/s²`），交融半径 `0–200 mm`。连续轴动限制为 `abs(direction×speed)`：XYZ 不超过 `250 mm/s`，其他轴不超过 `2.5 rad/s`。这些仅是接口输入范围，不是设备安全速度或可达性保证。

纯姿态线/圆运动另有条件：SDK对位置变化<1 mm且姿态变化>1e-4 rad的轨迹按角速度/角加速度处理；当前适配仍把velocity除1000，不能直接套用本页平移速度参考。本页参考保持姿态不变。其他品牌可能使用不同姿态表示和速度尺度，不能照搬Aubo约定。

## 运动请求示例

下面的目标由示例位置快照计算，速度和加速度是示例值，不是协议默认值。调用前必须根据目标设备重新读取当前位置，并完成可达性、碰撞、关节余量、工具坐标系和控制器状态检查。

### 轴向连续运动

Service `/at/robot/move_axis`，`weld_interfaces/srv/ATRobotMoveJog`：当前坐标系+X，10 mm/s。

```json
{
  "move_type": "X",
  "direction": 1.0,
  "speed": 10.0
}
```

J1 角轴示例为 `{"move_type":"J1","direction":1.0,"speed":0.1}`，即 `+0.1 rad/s`（约 `5.73°/s`）。未切换坐标系时使用基座系；工具/视角模式按当前坐标系处理。连续接口需要持续刷新；2 秒未刷新会请求停止。返回 200 仍不表示运动已经完成。

### 关节运动

Service `/at/robot/move_joint`，`weld_interfaces/srv/ATRobotMove`；或同名 Action、`weld_interfaces/action/ATRobotMove`。目标仅将示例 J1 增加 `0.01 rad`（约 `0.573°`），其余关节不变；速度 `0.1 rad/s`，加速度 `0.2 rad/s²`，交融 `0 mm`。

```json
{
  "mid_point": [],
  "end_point": [
    0.15538813539808397,
    -0.10732512781504386,
    1.2150040622010707,
    -0.14933041400185393,
    1.49344589401874,
    0.18374963528866972
  ],
  "velocity": 0.1,
  "blend_radius": 0.0,
  "acceleration": 0.2
}
```

### 直线运动

Service `/at/robot/move_line`，`weld_interfaces/srv/ATRobotMove`；或同名 Action、`weld_interfaces/action/ATRobotMove`。目标将示例基座 X 增加 `1 mm`，其他分量不变；速度 `10 mm/s`，加速度 `0.2 m/s²`（`200 mm/s²`）。

```json
{
  "mid_point": [],
  "end_point": [
    677.9761981510525,
    -84.91911734714634,
    43.39195991040368,
    0.015999066687914634,
    0.4119973636840914,
    0.024001748097261858
  ],
  "velocity": 10.0,
  "blend_radius": 0.0,
  "acceleration": 0.2
}
```

### 圆弧运动

Action `/at/robot/move_circle`，`weld_interfaces/action/ATRobotMove`。示例以位置快照为起点，途经点为 `X+0.5 mm、Y+0.5 mm`，终点为 `X+1 mm`，姿态不变。三点不共线；调用前仍需由目标控制器完成轨迹和可达性检查。

```json
{
  "mid_point": [
    677.4761981510525,
    -84.41911734714634,
    43.39195991040368,
    0.015999066687914634,
    0.4119973636840914,
    0.024001748097261858
  ],
  "end_point": [
    677.9761981510525,
    -84.91911734714634,
    43.39195991040368,
    0.015999066687914634,
    0.4119973636840914,
    0.024001748097261858
  ],
  "velocity": 10.0,
  "blend_radius": 0.0,
  "acceleration": 0.2
}
```

line/joint的mid_point：扩展字段，当前版本未使用，可不填。也可传[]；circle必须填写途经点。所有目标是绝对值，协议没有relative开关。

Service 返回 200 表示运动请求已由底层调用接受，不表示机器人已经到位。Action 还需检查 ROS 终态和业务 `result`；只有运动及到位等待都成功时才返回 200。反馈 `robot_pos` 是空格分隔的数值字符串：joint 使用 rad，line/circle 使用 xyz mm 和姿态 rad。
